# Puneet Khanna — Professional Portfolio

A responsive static portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a modern browser. For a local development server:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Before publishing
1. Verify the certification titles and active status against your Trailblazer profile.
2. Review role dates and descriptions for accuracy.
3. Add approved project case studies and further verified business outcomes.
4. Optionally add a professional headshot.
5. Confirm whether you want the public email address displayed.

The mobile number from the CV has intentionally not been published in this version.

## Deploy
This static site can be deployed using GitHub Pages, Netlify or Vercel. Upload this folder or connect its Git repository. No build command is required.
